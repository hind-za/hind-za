## 🚀 Projects I'm Proud Of

### 🤖 LLM Application Security Audit and Hardening
Gray-box audit of an internal LLM assistant (RAG + tool calling) following the OWASP Top 10 for LLM: prompt injection, data leakage, excessive agency. Attack success rates measured over multiple runs, then fixed (filters, RAG access control, tool validation) and re-tested to measure the before/after.

### 🏰 Full Active Directory Domain Compromise
End-to-end attack on an Active Directory lab: reconnaissance with BloodHound, password spraying, Kerberoasting, Golden Ticket via DCSync, NTDS.dit dump and Pass-the-Hash lateral movement — with remediation recommendations.

### 🔐 Enterprise Network Architecture & Hardening
Segmented architecture with pfSense, Client-to-Site VPN (OpenVPN, internal PKI), Ubuntu hardening (UFW, SSH) and Suricata as an inline IPS, validated with simulated network attacks (scans, brute force, flood).

### 🚗 Automotive Cyber Range
Built a Cyber Range platform on Proxmox VE dedicated to automotive security during my internship at Ovivia AI Solution: educational scenarios on automotive risks, CAN bus attack simulations, and PLC/SCADA attack reports turned into interactive scenarios.
